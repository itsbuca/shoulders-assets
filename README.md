# SHOULDERS — Brand Assets

Official public brand-asset repository for **SHOULDERS** and **WhichShoulder.com**.

## Repository purpose

This repository contains the approved public-facing SHOULDERS brand artwork and character assets.

It is intentionally separate from the CALL-IT application repository.

## Structure

- `logos/` — SHOULDERS wordmarks and composite logos
- `characters/` — Max and Oreo character artwork

## Brand characters

- **Max** — Angel / gold
- **Oreo** — Devil / dark blood red
